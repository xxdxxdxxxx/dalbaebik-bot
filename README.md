# Dalbaebik Bot — аналитика КВ-клана STALCRAFT

Discord-бот для управления составом и сбора статистики клана. Основной источник данных — SQLite; состав управляется через локальную админ-панель и синхронизируется с Clan Map и двумя постоянными сообщениями Discord.

## Возможности

- 6 отрядов по 5 игроков и отдельная группа замен;
- игроки с Discord-привязкой и без неё;
- «ЯВКА НА КВ» и «ГРАНАТЫ» обновляются автоматически;
- явка по голосовым каналам и автоматические ЛС неявившимся;
- автоматический подсчёт активной речи;
- замеры гранат через STALCRAFT eAPI;
- распознавание табов через Gemini OCR;
- статистика и ЭФФ в локальной админ-панели;
- синхронизация состава с Clan Map;
- восстановление незавершённой сессии после перезапуска.

## Команды

- состав: `/add`, `/remove`, `/alias_add`, `!add`, `!remove`;
- КВ: `/map`, `!map`, `/refresh`, `/scan_now`, `/ls_send`;
- табы: `/scan`;
- настройка: `/setup`, `/set_log`, `/settings`, `/voice_add`, `/voice_remove`, `/voice_clear`;
- права: `/access_add`, `/access_remove`, `/access_list`;
- служебные: `/say`, `/help`.

Случайные фразы после добавления игрока и текстовые команды сохранены. Статистика, история табов и рейтинг эффективности доступны только в админ-панели.

## Админ-панель

Панель слушает только `127.0.0.1:8787` (порт наружу не открывается никогда).

**Локально / через SSH-туннель** — как раньше, без пароля: `ssh -L 8787:127.0.0.1:8787 user@host`, затем `http://localhost:8787`.
Пока `ADMIN_PASSWORD` не задан, панель отвечает только на `localhost`; любой запрос через прокси или по чужому имени хоста получает 403.

**Из интернета по паролю** — в `.env` добавьте:

```
ADMIN_PASSWORD=<длинный случайный пароль>
ADMIN_TRUST_PROXY=1
```

и поставьте перед панелью HTTPS-прокси (Caddy / Cloudflare Tunnel / Tailscale Funnel), который проксирует на `127.0.0.1:8787`.
Вход: форма пароля → cookie на 7 дней (`ADMIN_SESSION_DAYS`). Защита: HTTPS обязателен, cookie `HttpOnly; Secure; SameSite=Lax`,
проверка `Origin` на POST, 5 неверных паролей с одного IP → блокировка на 15 минут, смена пароля разлогинивает всех.
Пример для Caddy:

```
panel.example.com {
    reverse_proxy 127.0.0.1:8787
}
```
