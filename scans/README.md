# scans/ · логи сканов гранат

```
scans/
├── etapy/     ← каждый этап
└── itogi/     ← итог дня (после финала)
```

## Формат

```
2026-07-23  четверг  21:15 МСК
Этап III
игроков: 35

ник                               I     II    III      ИТОГ  ВРЕМЯ
---------------------------------------------------------------------
Отряд 1:
sosew(discord_username)            —      —     21        21   12:34
```

Имя игрока сохраняется как `игровой_ник(discord_username)`; если Discord username отсутствует в локальной базе, остаётся прежний игровой ник без скобок. Ширина первой колонки подстраивается под самое длинное имя.

Ячейки — **дельты gre-thr** за этап. В итоговом файле колонка **ВРЕМЯ** содержит суммарное время речи за сессию в формате `мм:сс` (включая `00:00`).

**чт–сб:** 20:05 / 25 / 50 / 21:15
**вс:** 19:00 / 20 / 40 · 20:00 / 20:15
