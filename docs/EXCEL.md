# Excel · отряды

## Один файл

Бот читает путь из `.env` → `SHEET_PATH`  
(по умолчанию `ДИТЯ22.xlsx` в корне проекта или hardlink на OneDrive).

## Как править

1. Открой **тот же** файл, что в `SHEET_PATH` (не «копию (1)»).
2. Поменяй ники по отрядам.
3. **Ctrl+S**
4. В Discord: `/sheet_sync` (или подожди ~1 мин).

Не включай «Автосохранение», если Excel утаскивает в другую копию на `d.docs.live.net`.

## Красивая таблица (Лист1) — жёсткие ячейки

Бот читает **только** эти диапазоны (остальное игнорируется):

| Отряд | Ячейки Excel |
|-------|----------------|
| Отряд 1 | **C6:C10** |
| Отряд 2 | **D6:D10** |
| Отряд 3 | **E6:E10** |
| Отряд 4 | **C12:C16** |
| Отряд 5 | **D12:D16** |
| Отряд 6 | **E12:E16** |
| Чемпионы (замены) | **F6:F16** |

```
     C         D         E         F
5    1         2         3         Замены
6-10 отряд1    отряд2    отряд3    чемпионы…
11   4         5         6
12-16 отряд4   отряд5    отряд6    чемпионы…
```

Заметки вне этих ячеек (типа «КТРЛ+S») бот не трогает.

## Кто есть кто (Discord)

1. `/add` · `!add` · `/remove` · `!remove` → `players.json`
2. Лист **tech** (`game_nick` | `discord_id`, id **текстом**) **обновляется сам**
   после add/remove (и после синка, если в Excel сменился ник).
3. **Лист1** бот только читает (отряды) — руками правишь ники по ячейкам.
